# 🐍 Python Finance Foundations

## 🎯 Objectif

Cette série de 25 exercices constitue ma base d'apprentissage Python orientée Data Analysis Finance.

L'objectif était de maîtriser progressivement :

- les variables ;
- les conditions ;
- les boucles ;
- les fonctions ;
- les structures de données ;
- les premiers indicateurs financiers.

---

# Partie 1 — Python Fundamentals

## Exercices 1 à 10

Notions abordées :

- variables ;
- types de données ;
- listes ;
- dictionnaires ;
- conditions ;
- boucles.

Objectif :

Comprendre les bases nécessaires pour manipuler des données financières.

---

# Partie 2 — Functions & Data Processing

## Exercices 11 à 19

Notions abordées :

- création de fonctions ;
- paramètres ;
- valeurs de retour ;
- manipulation de séries de données.

Premières applications :

- calcul de rendements ;
- analyse de variations ;
- manipulation de données de marché.

---

# Partie 3 — Financial Indicators

## Exercices 20 à 25

Création de premières fonctions utilisées en analyse financière :

## 📊 Portfolio return

Calcul du rendement global d'un portefeuille.

## 🏆 Best asset selection

Identification de l'actif avec la meilleure performance.

## 📉 Volatility

Introduction à l'écart-type comme mesure du risque.

## 📈 Average return

Calcul du rendement moyen.

## 📉 Maximum drawdown

Mesure de la perte maximale depuis un sommet.

## 📊 Asset summary

Combinaison de plusieurs indicateurs financiers.

# 🚀 Vers le Trading Risk Dashboard

Ces exercices constituent la base du projet final :
