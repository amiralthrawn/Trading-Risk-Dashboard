# Trading-Risk-Dashboard
Trading Risk Dashboard built with Python, Pandas and Streamlit.

## Présentation 

Ce dépôt documente ma progression dans le développement d'un tableau de bors d'analyse des marchés financiers avec Python. 

L'objectif final est d'etre capable d'analyser des données de marché et d'afficher différents indicateurs de risque et de performance, notamment :

- Rendement
- Volatilité
- Drawdown
- Moyennes mobiles
- Tableaux et graphiques interactifs

Avant de développer ceci, je construis progressivement les bases en Python à travers une série d'exercices appliqués à la finance.

Chaque exercice répond à un problème concret rencontré dans l'analyse des marchés.
